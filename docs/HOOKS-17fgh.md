- Gating inside `rig.update`: off screen = no mixer step (time is kept and applied when it comes back); beyond `CHR.anim.nearM` (30 m) = `farHz` (10 Hz) steps; LOD by THREE.LOD with `CHR.lod` distances x `lodK` (phone 0.6).
